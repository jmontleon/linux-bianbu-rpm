# SpacemiT kernel
This repo contains build artifacts for Fedora kernels.

Patches are generated from [jmontleon/linux-spacemit](https://github.com/jmontleon/linux-spacemit)

Patches for stable were originally taken from [spacemit-com/linux-k1x](https://github.com/spacemit-com/linux-k1x)

Older LTS kernel patches were from Bianbu repos on gitee. [https://gitee.com/bianbu-linux/linux-6.6](https://gitee.com/bianbu-linux/linux-6.6)
